# MonitorioRent

MonitorioRent — сервіс пошуку та розміщення квартир в оренду в Україні.

## Що вже працює

- перше питання кабінету: **«Орендую» або «Здаю»**;
- збереження основної ролі користувача;
- форма пошуку за містом, районом, бюджетом, кімнатами, тваринами,
  комісією та типом автора;
- покрокова форма власного оголошення;
- завантаження до восьми фотографій;
- автоматичне локальне збереження чернетки форми;
- статус нового оголошення «На перевірці»;
- кабінет зі збереженими пошуками та власними оголошеннями;
- адаптивний Telegram Mini App у стилі Monitorio;
- SQLite-сховище та FastAPI.
- Telegram-бот із командами `/start` і `/cabinet`;
- автоматичний пошук свіжих збігів і сповіщення кожні 30 хвилин;
- імпорт із публічних Telegram-каналів та офіційного DIM.RIA API;
- захищений API для схвалення або відхилення оголошень.

## Локальний запуск

```powershell
cd C:\cs2manager\MonitorioRent
.\run.ps1
```

Після запуску відкрийте `http://127.0.0.1:8020`.

Для запуску Telegram-бота задайте `TELEGRAM_BOT_TOKEN` і публічний HTTPS URL
кабінету в `MONITORIO_RENT_MINI_APP_URL`, після чого виконайте:

```powershell
.\run_bot.ps1
```

## Перевірка

```powershell
python -m unittest discover -s tests -v
```

## API

- `GET /api/state` — роль, пошуки, власні оголошення та стрічка;
- `POST /api/profile` — вибір «Орендую» або «Здаю»;
- `POST /api/searches` — створення пошуку;
- `DELETE /api/searches/{id}` — видалення пошуку;
- `POST /api/listings` — розміщення власного оголошення з фото;
- `GET /api/listings` — публічна стрічка оголошень.
- `GET /api/sources` — перелік Telegram/DIM.RIA джерел і стан синхронізації;
- `POST /api/admin/sources/sync` — ручний захищений запуск імпорту джерел;
- `GET /api/admin/listings` — черга модерації;
- `POST /api/admin/listings/{id}/status` — зміна статусу оголошення.

## Telegram-джерела

MonitorioRent кожні 30 хвилин читає публічні веб-сторінки вибраних каналів, витягує
місто, район, ціну, кімнати, площу, поверх, комісію та умови щодо тварин, а потім
дедуплікує оголошення за каналом і ID допису. У картці завжди зберігається пряме
посилання на оригінальний допис. Інтервал задається через
`MONITORIO_RENT_SYNC_INTERVAL`, а імпорт можна вимкнути через
`MONITORIO_RENT_TELEGRAM_SYNC=0`.

Користувач обирає період свіжості: 1, 3 або 7 днів. Після збереження пошуку Mini App
одразу показує збіги, а бот протягом кількох секунд надсилає підсумок. Якщо збігів
немає, бот повідомляє про це один раз і продовжує моніторинг. Нове оголошення для
того самого пошуку надсилається лише один раз. Перевірка джерел примусово обмежена
мінімальним інтервалом 1800 секунд.

Фото Telegram беруться з публічної сторінки допису. У базі зберігається до восьми
URL; бот надсилає перше фото з карткою та кнопкою на оригінал. Якщо CDN не дозволяє
Telegram завантажити зображення, бот надсилає текстову картку замість втрати збігу.

## DIM.RIA

Офіційний адаптер активується змінною `DIM_RIA_API_KEY`. Один централізований пошук
запускається разом з іншими джерелами, а детальні картки завантажуються лише для
ще невідомих ID. DIM.RIA запускається не частіше одного разу на 2 години та бере
не більше однієї нової детальної картки за цикл. Вбудований місячний бюджет — 900
запитів, щоб залишити резерв із пакета на 1000. Параметри задаються через
`DIM_RIA_MIN_INTERVAL_SECONDS`, `DIM_RIA_MAX_DETAILS_PER_RUN` і
`DIM_RIA_MONTHLY_BUDGET`. Лічильник та блокування зберігаються в SQLite, тому два
процеси або перезапуск не дублюють запити. Оголошення локально дедуплікуються, фотографії
беруться з детальної відповіді API, а кожна картка веде на оригінал DIM.RIA.

Неавторизований скрейпінг OLX/LUN не вмикається: для них потрібен узгоджений API або
письмовий дозвіл.

Для доларових оголошень можна задати курс через `MONITORIO_RENT_USD_UAH_RATE`.
Без нього показується оригінальна ціна, але таке оголошення не потрапляє у вибірку
з максимальним бюджетом у гривнях.

## Що ще не підключено

- графічний модераторський інтерфейс (API модерації вже є);
- інші зовнішні джерела крім DIM.RIA;
- production-перевірка Telegram `initData`.

Поточна авторизація користувача підходить лише для MVP. Перед публічним запуском
сервер має перевіряти підпис Telegram `initData`.

Не додавайте в Git токени ботів, API-ключі, файли `.env`, бази даних, фото
користувачів або логи.
