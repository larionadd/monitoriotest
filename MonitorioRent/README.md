# MonitorioRent

MonitorioRent — сервіс пошуку та розміщення квартир в оренду в Україні.

## Що вже працює

- перше питання кабінету: **«Орендую» або «Здаю»**;
- збереження основної ролі користувача;
- форма пошуку за містом, районом, бюджетом, кімнатами, тваринами,
  комісією та типом автора;
- покрокова форма власного оголошення;
- завантаження до восьми фотографій;
- автоматичне локальне збереження чернетки форми;
- статус нового оголошення «На перевірці»;
- кабінет зі збереженими пошуками та власними оголошеннями;
- адаптивний Telegram Mini App у стилі Monitorio;
- SQLite-сховище та FastAPI.
- Telegram-бот із командами `/start` і `/cabinet`;
- захищений API для схвалення або відхилення оголошень.

## Локальний запуск

```powershell
cd C:\cs2manager\MonitorioRent
.\run.ps1
```

Після запуску відкрийте `http://127.0.0.1:8020`.

Для запуску Telegram-бота задайте `TELEGRAM_BOT_TOKEN` і публічний HTTPS URL
кабінету в `MONITORIO_RENT_MINI_APP_URL`, після чого виконайте:

```powershell
.\run_bot.ps1
```

## Перевірка

```powershell
python -m unittest discover -s tests -v
```

## API

- `GET /api/state` — роль, пошуки, власні оголошення та стрічка;
- `POST /api/profile` — вибір «Орендую» або «Здаю»;
- `POST /api/searches` — створення пошуку;
- `DELETE /api/searches/{id}` — видалення пошуку;
- `POST /api/listings` — розміщення власного оголошення з фото;
- `GET /api/listings` — публічна стрічка оголошень.
- `GET /api/admin/listings` — черга модерації;
- `POST /api/admin/listings/{id}/status` — зміна статусу оголошення.

## Що ще не підключено

- графічний модераторський інтерфейс (API модерації вже є);
- DIM.RIA API та інші зовнішні джерела;
- автоматичне зіставлення нових оголошень із пошуками;
- Telegram-сповіщення;
- production-перевірка Telegram `initData`.

Поточна авторизація користувача підходить лише для MVP. Перед публічним запуском
сервер має перевіряти підпис Telegram `initData`.

Не додавайте в Git токени ботів, API-ключі, файли `.env`, бази даних, фото
користувачів або логи.
