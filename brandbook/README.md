# Monitorio Brand Book

Файли брендбуку Monitorio.

## Основний файл

- `monitorio-brandbook.html` - адаптивний брендбук українською мовою.

## Логотипи та аватари

- `assets/monitorio-logo-source.jpg` - оригінал, наданий користувачем.
- `assets/monitorio-logo-full.png` - повний логотип із написом Monitorio.
- `assets/monitorio-logo-lockup.png` - повний квадратний lockup.
- `assets/monitorio-avatar-1024.png` - аватар для соцмереж і Telegram у високій якості.
- `assets/monitorio-avatar-512.png` - стандартний аватар.
- `assets/monitorio-avatar-256.png` - малий аватар.
- `assets/monitorio-avatar-128.png` - favicon / маленька іконка.

## Коротке правило

Для аватарів використовуйте тільки `monitorio-avatar-*`, бо повна версія з написом не читається в малому розмірі.
